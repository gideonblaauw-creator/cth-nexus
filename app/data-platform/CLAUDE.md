
## Knowledge Graph

This project has a Graphify knowledge graph in `graphify-out/`.
Before scanning files to answer structural questions, consult:
- `graphify-out/graph.json` for machine-readable relationships
- Use `graphify query "<question>"` to query the graph directly
- Use `graphify path "<nodeA>" "<nodeB>"` to find connection paths
- Use `graphify explain "<node>"` for plain-language node explanations
